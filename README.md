# 🎓 Student Registration System

A simple Student Registration System built using **HTML**. This project allows users to fill out a student registration form and displays the submitted student information in a table. It is a beginner-friendly project that helps in understanding HTML forms and table structures.

---

## 📖 About the Project

The Student Registration System is a basic web page created using only **HTML**. It includes a registration form where users can enter student details. The submitted information is then shown in a table format for easy viewing.

This project is mainly created for learning and practicing HTML concepts.

---

## ✨ Features

- Student registration form
- Clean and simple design
- Easy-to-use interface
- Display student details in a table
- Beginner-friendly project
- Built using only HTML

## 📋 Student Information

The registration form can include the following details:

- Student Name
- Student Email
- Password
- Gender
- Skills
- Date of Birth


These details are displayed in a table with separate columns for each field.
